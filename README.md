📊 Exemplo de análise

O projeto utiliza dados de:

Dia
Produto
Quantidade
Preço
Faturamento


A partir desses dados são realizadas análises como:

df["faturamento"] = df["Preco"] * df["Quantidade"]

faturamento_total = df["faturamento"].sum()

media_faturamento = df["faturamento"].mean()

vendas_produto = df.groupby("Produto")["Quantidade"].sum()
