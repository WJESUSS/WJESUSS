## 📈 Projeto em Destaque

### 🛒 Projeto de Análise de Vendas

Projeto desenvolvido em Python com foco na análise de dados de vendas.

**🎯 Objetivo:** obter indicadores como:

- Quantidade total vendida
- Faturamento total e médio
- Quantidade vendida por produto
- Produtos com maior volume de vendas
- Análise gráfica dos resultados

**🐍 Tecnologias:** Python · Pandas · Matplotlib · Jupyter Notebook · Git · GitHub

**📊 Exemplo de análise:** o projeto utiliza dados de *Dia, Produto, Quantidade, Preço e Faturamento*.

```python
df["faturamento"] = df["Preco"] * df["Quantidade"]

faturamento_total = df["faturamento"].sum()

media_faturamento = df["faturamento"].mean()

vendas_produto = df.groupby("Produto")["Quantidade"].sum()
```

Esse projeto faz parte da minha jornada prática de aprendizado em Análise de Dados com Python.
